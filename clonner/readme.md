# ⚡ GitHub Mass Cloner
## ¿Qué hace?
Script en Bash que utiliza la GitHub CLI (gh) para listar y clonar automáticamente todos los repositorios públicos de un usuario específico directamente a tu entorno Linux/WSL.
## Propósito
Automatizar la extracción masiva de código fuente para estudio técnico, auditoría de lógica y análisis de arquitecturas de software sin intervención manual.
